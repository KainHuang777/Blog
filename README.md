# 🌌 Kain's AI Space - 部落格寫作與目錄管理手冊

歡迎使用您的個人 AI 學習部落格！本專案採用 **極簡純前端靜態方案（KISS）**，沒有複雜的 Node.js 編譯步驟。

本手冊將詳細引導您如何放置已完成的內容、如何管理目錄結構，以及如何快速發布新文章。

---

## 📁 專案目錄結構概覽

部落格的目錄結構極為乾淨清晰，請對照以下結構進行檔案管理：

```text
Blog/
├── index.html              # 部落格首頁（展示文章列表、自我介紹與標籤過濾）
├── post.html               # 文章詳情閱讀頁（動態解析 Markdown、代碼高亮）
├── posts.json              # 📝 文章索引資料庫（新文章必須在此註冊！）
├── netlify.toml            # Netlify 部署設定檔（控制快取與安全性）
├── Update.txt              # 更新日誌檔（記錄每次網站代碼更新）
├── test_blog_server.py     # 🧪 本地測試與完整性診斷工具
├── README.md               # 📖 您正在閱讀的寫作說明手冊
│
├── posts/                  # ✍️ 專門存放文章 Markdown 檔案的目錄
│   ├── hello-world.md      # 首篇範例文章
│   └── [您的文章ID].md     # 未來您的新文章（檔名須與 posts.json 的 id 相同）
│
└── assets/                 # 🎨 靜態資源目錄
    ├── css/
    │   └── style.css       # 科技感深色樣式表
    ├── js/
    │   └── app.js          # 首頁動態渲染與 Markdown 解析邏輯
    └── images/             # 🖼️ 專門存放文章內圖片與個人頭像的目錄
```

## 🚀 撰寫與發布新文章 (強烈推薦自動化)

為了預防人工修改 JSON 檔案時因漏掉逗號或引號而產生格式毀損，同時也為了自動為您快速生成 Markdown 模板，專案特別為您配備了強大的 **「本地寫作與部落格管理 CLI 助手 (`manage_blog.py`)」**。

### 🤖 方法一：使用本地管理助手 (推薦 ── 100% 安全防錯)

在專案根目錄下打開終端機 (PowerShell 或 Cmd)，執行以下指令：
```powershell
python manage_blog.py
```

這套助手會以充滿科技感的彩色命令行交互菜單引導您進行以下維護：
1.  **`[1] ✍️ 創建新文章`**：輸入文章 ID、標題、主要分類、輔助標籤與摘要。助手會**自動為您生成 `posts/[文章ID].md` 寫作檔案模板**，並且** 100% 格式正確地在 `posts.json` 中完成註冊**！
2.  **`[2] 📂 管理與修改現有文章之分類與標籤`**：動態列表顯示當前所有文章與分類。直接輸入序號即可在安全的介面中修改任何文章的分類、標籤、標題或摘要。
3.  **`[3] 🗑️ 下架封存文章`**：選擇對應編號並確認後，助手會一鍵從網頁上註銷移除該文章，並**自動將實體 Markdown 檔案安全移至備份封存目錄 `posts_archive/`**，實體檔案絕對安全不丟失。
4.  **`[4] 🧪 一鍵本地測試與診斷`**：直接在菜單中選擇項目 `[4]`，會自動啟動專案完整性診斷並執行本地 `8000` 測試伺服器，免除您手動在終端機輸入測試指令的繁瑣！
5.  **`[5] 🚀 版本控制與 GitHub 雲端部署`**：一鍵開啟獨立的 Git 工具箱子選單。支援彩色查看 Git 變更檔案狀態、一鍵本地 Commit 備份（若本地尚未 init，會主動引導一鍵初始化）、一鍵 Push 同步到遠端 GitHub 倉庫（若尚未綁定 remote 則引導輸入 HTTPS URL 自動綁定），**自動觸發線上 Netlify 流水線一鍵更新**！

### 📝 方法二：純手動管理方式 (備用備查)

如果您在某些情況下想採取純手動方式新增文章，請遵循以下步驟：

#### 🛑 步驟一：將 Markdown 檔案放入 `posts/` 目錄
1. 將您的文章另存為 `.md` (Markdown) 格式。
2. 將檔案命名為小寫英文字母、數字與連字號的組合（例如：`ai-learning-02.md`）。**請避免使用中文檔名或特殊字元**。
3. 將該檔案放入 `posts/` 資料夾內。

#### 📝 步驟二：在 `posts.json` 中手動註冊您的文章
打開 `posts.json`，在數組陣列的適當位置追加該文章的資訊物件（注意結尾的逗號格式）：
```json
  {
    "id": "ai-learning-02",
    "title": "大語言模型 Prompts 提示詞工程最佳實踐",
    "date": "2026-05-29",
    "tags": ["AI 學習", "Prompt", "LLMs"],
    "summary": "深入探討如何撰寫高效的 System Prompt，並解析 Few-shot、CoT 技術的應用場景。"
  }
```
*   `id`：必須與您在 `posts/` 中放置的 Markdown 檔案名稱**完全一致** (不含 `.md` 後綴)。
*   `tags`：陣列中的**第一個標籤**將被智慧演算法自動提取為「筆記分類」，其餘標籤則自動歸入「學習領域標籤雲」。

#### 🧪 步驟三：運行本地測試伺服器
1. 打開終端機，切換到專案目錄：
   ```powershell
   cd d:\Temp\temp\Blog
   ```
2. 運行獨立測試伺服器：
   ```powershell
   python test_blog_server.py
   ```
3. 在瀏覽器打開 `http://localhost:8000` 確認結果。

## 🖼️ 如何在文章中插入圖片與管理？

如果您的 AI 學習筆記中包含圖片、架構圖或螢幕截圖，請照以下方式管理：

1.  **存放圖片**：將圖片檔案（例如 `llm-agent-arch.png`）放入 `assets/images/` 目錄中。
2.  **在 Markdown 中引用**：在您的 `.md` 檔案中，使用**相對路徑**引用該圖片，語法如下：
    ```markdown
    ![LLM 智慧體架構圖](assets/images/llm-agent-arch.png)
    ```
    *※ 前端網頁在渲染時會自動解析該路徑並完美載入圖片！*

## 🌐 Netlify 部署管理指南

既然您已經在 Netlify 建立了專案，您可以選擇以下兩種方式來管理與更新您的線上部落格：

### 方案一：Git 自動同步部署（🌟 強烈推薦，最專業）
如果您將此 `Blog/` 目錄初始化為 Git 倉庫，並推送至 GitHub / GitLab：
1. 在 Netlify 控制台將您的專案連結到該 GitHub 倉庫。
2. 設定 Netlify 的 **Publish directory（發布目錄）** 為 `.` (即根目錄，也是默認值)。
3. 設定 **Build command（建置指令）** 為空（因為方案 A 不需要建置）。
4. **未來更新**：只要您在本地新增文章，執行 `git add .`、`git commit -m "add new post"`、`git push`，**Netlify 就會自動在一秒內完成線上更新**！

### 方案二：手動拖曳上傳部署（適合不想使用 Git 的情境）
1. 登入 Netlify 後，進入您的專案頁面。
2. 找到 **Deploys** 標籤頁。
3. 頁面下方會有一個拖曳上傳區域（`Drag and drop your site folder here`）。
4. 直接將本地的整個 `Blog` 資料夾拖曳進去，即可立刻完成線上更新！
