# 沖繩經典四日遊 - 互動網頁

一個以精美視覺設計與互動體驗為核心的沖繩旅遊行程網頁。

## 專案目的

測試 AI 模型（Qwen 3.7 MAX）在網頁設計、CSS 動畫與視覺美感方面的能力。

## 行程概覽

| 天數 | 主題 | 重點景點 |
|------|------|----------|
| Day 1 | 台北 → 沖繩 | 那霸空港、飯店 Check-in |
| Day 2 | 中部海洋與美式風情 | 萬座毛、美之海水族館、美國村 |
| Day 3 | 全日自由活動 | 主題未定（動態切換） |
| Day 4 | 市區文化巡禮 → 返台 | 波上宮、免稅店、國際通 |

## 技術架構

- **HTML5** - 語意化結構
- **CSS3** - 漸層、動畫、毛玻璃效果、RWD 響應式設計
- **Vanilla JavaScript** - 互動邏輯、動態主題切換、捲動動畫
- **無外部框架依賴** - 純原生技術實現

## 主要功能

- 每日行程卡片式展示與詳細景點介紹
- Day 3 自由行動態主題切換
- 捲動視差與進場動畫
- 響應式設計（桌機 / 平板 / 手機）

## 使用方式

直接在瀏覽器開啟 `index.html` 即可瀏覽。

```bash
# 或使用本地伺服器
npx serve .
# 或
python -m http.server 8080
```
