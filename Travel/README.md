# 創連科技｜沖繩 4 日員工旅遊 - 互動網頁

以確認版行程資料製作的沖繩員工旅遊互動網頁。

## 專案目的

測試 AI 模型（Qwen 3.7 MAX）在網頁設計、CSS 動畫與視覺美感方面的能力。

## 行程概覽

| 天數 | 主題 | 重點景點 |
|------|------|----------|
| Day 1 | 桃園 → 沖繩 | FD230、HOTEL LANTANA NAHA MATSUYAMA |
| Day 2 | 海洋、泡盛與美式風情 | 美麗海水族館、泡盛酒廠、美國村 |
| Day 3 | 全日自由活動 | 單軌電車一日券、新都心／國際通／牧志市場 |
| Day 4 | 文化巡禮 → 返台 | 波之上神宮、藥妝店／免稅店、系滿漁市場、FD231 |

## 技術架構

- **HTML5** - 語意化結構
- **CSS3** - 漸層、動畫、毛玻璃效果、RWD 響應式設計
- **Vanilla JavaScript** - 互動邏輯、動態主題切換、捲動動畫
- **無外部框架依賴** - 純原生技術實現

## 主要功能

- 每日行程卡片式展示與詳細景點介紹
- Day 3 自由行建議主題切換
- 捲動視差與進場動畫
- 響應式設計（桌機 / 平板 / 手機）

## 使用方式

直接在瀏覽器開啟 `index.html` 即可瀏覽。

```bash
# 或使用本地伺服器
npx serve .
# 或
python -m http.server 8080
```

