## ── 核心架構與方法論 ──

V3.0 基準測試建立了高度防偏見的嚴格評判體系，其核心由以下四大支柱構成：

```
                    ┌──────────────────────────────────────────────┐
                    │            LLM Benchmark V3.0                │
                    └──────────────────────┬───────────────────────┘
                                           │
         ┌───────────────────┬─────────────┴──────┬───────────────────┐
         ▼                   ▼                    ▼                   ▼
   【四裁判評審團】    【同模型自評迴避】     【評分校準輪機制】    【雙重客觀扣分制】
    - J1: mimo-v2.5-pro  - J1 迴避 J1 參賽     - 標準樣品章節 04     - 字數雙向懲罰
    - J2: mimo-v2-omni   - J2 迴避 J2 參賽     - 收斂最大分歧        - 禁用詞/事實 Checklist
    - J3: deepseek-flash - J3 迴避 J3 參賽     - 量尺對齊 J1-J4      - 上限分別為 -1/-2
    - J4: gemini-3.5-med - J4 迴避 J4 參賽
```

### 1. 四裁判評審團 (The Four-Judge Panel)
本體系引入了四個表現優異的獨立大語言模型，組成交叉裁判團，針對所有參賽正文實施**等權重 12.5%** 的交叉盲測：
*   **J1**: `mimo-v2.5-pro`（小米，外部 API 連接）
*   **J2**: `mimo-v2-omni`（小米，外部 API 連接）
*   **J3**: `deepseek-v4-flash`（深度求索，直連 API）
*   **J4**: `gemini-3.5-flash-med`（Google AI，Antigravity 集成）

### 2. 同模型自評完全排除 (Mathematical Self-Exclusion)
大語言模型作為裁判時，天然傾向於給予自己生成的文字以極高的讚賞。
**V3 實施了嚴格的數學迴避機制**：
*   當被評估的參賽模型與裁判模型完全一致時，該裁判的分數被徹底剔除（在明細表中標記為 `-`）。
*   參賽模型的最終基礎分數將自動改由**其餘三位獨立裁判**的平均分計算。
*   此舉徹底解決了「既當選手又當裁判」的系統性自愛偏見，使模型排名回歸客觀。

### 3. 校準輪量尺機制 (Scoring Calibration)
為確保四位裁判對 10 分制量規的審美基準高度一致，在正式評分前實施了**樣品校準**：
*   **校準樣品**：`chapters/04-cloud-service-misunderstanding.md`（字數 3,242 字，內容包含對話、AI 元素、千禧年細節與幽默自嘲）。
*   **校準結果**：寫入 `calibration-results.json`，確認四位裁判在各維度的評分最大分歧度小於等於 2 分（多數維度小於 1.5 分），成功收斂裁判團隊量尺。

### 4. Checklist 扣分與史實核查 (Objective Compliance Checklist)
為限制 AI 生成內容中常見的「填充句」、「史實穿越」與「翻譯腔」，新設客觀核查扣分機制：
*   **字數雙向懲罰**：參賽章節的目標字數為 **2500 - 3500 字**。
    *   低於 2500 字：每少 1000 字扣 0.5 分。
    *   高於 3500 字：每多 2000 字扣 0.5 分。
    *   字數合理性扣分上限為 **-1.0 分**。
*   ** Checklist 核查項**（每項違規扣 0.5 分，扣分上限為 **-2.0 分**）：
    *   *風格禁用詞*：瞳孔微缩、嘴角勾起一抹弧度、璀璨、不羁。
    *   *AI 推進套話*：空氣突然安靜了、話音落下、沉默在兩人之間瀰漫、他意識到、她終於開口。
    *   *史實事實核查*：例如 2000 年的小說情節中禁止出現 Sasser 蠕蟲病毒（2004爆發，若出現扣 2 分）或 CodeRed（2001爆發，若出現扣 1 分）。
    *   *語法核查*：生硬翻譯腔（「被……所」、「在……之下」過度使用）。

## ── 八大評估維度與權重 ──

基準測試對每篇第一章進行八個維度的多點評判，各佔 **12.5%** 的權重：

| 評估維度 | 考核焦點 | 權重 |
| :--- | :--- | :--- |
| **文筆 (Writing Style)** | 文字流暢度、文學質感、白描技巧，避免華而不實的堆砌。 | 12.5% |
| **年代感 (Nostalgia)** | 2000 年時代背景（如 Win98, MSN, 澳門幣, 舊關閘, 33.6k 貓）還原度。 | 12.5% |
| **角色塑造 (Character)** | 主角黃雲龍的冷靜與疲憊感、配角的市井味與立體度。 | 12.5% |
| **幽默感 (Humor)** | 輕鬆幽默的基調、工程師冷笑話、年代錯位產生的幽默自嘲。 | 12.5% |
| **對話品質 (Dialogue)** | 簡潔有力、富含信息量、符合人物特徵的對話，拒絕套話。 | 12.5% |
| **節奏感 (Pacing)** | 開篇場景切換的流暢度，情節鋪陳不拖泥帶水，懸念恰到好處。 | 12.5% |
| **AI元素 (AI Integration)** | 未來模型「小龍蝦」降級運行與主角互動的合理性與趣味性。 | 12.5% |
| **開篇吸引力 (Hook)** | 生理錯位震撼開篇，24小時賺錢的核心衝突與利益驅動力。 | 12.5% |

## ── 目錄資產說明 ──

### 1. 參評模型目錄 (20 Models)
本目錄下包含 20 個主流模型的輸出與評分文件夹。

每個模型目錄均包含：
*   `chapter-01.md`：該模型基於控制卡生成的小說第一章正文。
*   `eval-v3-mimo-v2.5-pro.md`：裁判 1 的 8 維度詳細評語與 JSON 給分。
*   `eval-v3-mimo-v2-omni.md`：裁判 2 的 8 維度詳細評語與 JSON 給分。
*   `eval-v3-deepseek-v4-flash.md`：裁判 3 的 8 維度詳細評語與 JSON 給分。
*   `eval-v3-gemini-flash-v3.5.md`：裁判 4 的 8 維度詳細評語與 JSON 給分（由 V2 評分高精度平移）。

### 2. 核心代碼與腳本
*   `copy_v3_gemini_scores.py`：自動將第四裁判的評分拷貝至 V3 目錄下並執行自評排除的資料處理指令碼。
*   `generate_v3_4judge_report.py`：核心匯總計算腳本，負責加權總分、自評數學排除、字數動態扣分、Checklist 檢索、分歧度計算並產出報表。

### 3. 資料庫與最終產出
*   `v3-raw-scores.json`：包含所有模型、所有裁判在各維度的詳細給分與文字原因的原始資料庫。
*   `v3-results.json`：包含最終平均分、扣分項、分歧警示與裁判明細的計算結果資料庫。
*   `v3-report.html`：**最終視覺化基準測試報告**，支持渠道對照、廠商平均实力對比、裁判間差分警示與詳細給分明細。

## ── 執行評估與報告生成 ──

若您需要重新生成 V3 基準測試數據與報告，請確保 Python 環境已安裝，並在終端執行：

```powershell
# 進入 llm-benchmark 目錄
cd d:\Temp\temp\novelist\llm-benchmark

# 運行四裁判數據匯總與報告生成器
python generate_v3_4judge_report.py
```

### 腳本執行邏輯：
1.  **資料加載與防禦性校驗**：讀取 20 個模型目錄下的 `eval-v3-*.md` 文件，自動檢索 markdown 中的 ```json 程式碼塊，如發現 JSON 語法缺失則採取防禦性容錯。
2.  **同名自評迴避**：若發現選手名與裁判名完全一致，自動跳過，不將該分數計入 `model_scores[dim]`。
3.  **計算字數與 Checklist**：分析各 `chapter-01.md` 的字符長度（過濾空白字元），並比對硬性禁用詞。
4.  **計算最終得分**：應用字數合理性懲罰與違規扣分，計算最終排名。
5.  **寫入資料庫並渲染精美 HTML 報告**。

## ── 統計與核心結論摘要 ──

根據最新的 V3.0 基準測試正式數據（20模型 · 四裁判評分 · 自評迴避）：

*   **全體平均分**：7.89 分
*   **全體中位數**：7.96 分
*   **最高總分得主**：`claude-4.6-opus`（**8.60分**，基礎分達 8.88，字數超出扣 0.275 分，其年代感與 AI 元素備受好評）。
*   **第二名**：`gtp5.5`（**8.58分**，基礎分達 8.78，字數扣 0.202 分）。
*   **第三名**：`claude-4.5-Haiku`（**8.47分**，基礎分 8.47，無字數扣分）。
*   **迴避機制有效性證明**：Gemini 3.5 Flash 在迴避自評分後，最終以客觀裁判均分計算，取得了中游的排名，有力證明了防偏見機制的科學性與公正性。
*   **分歧度警示**：在幽默感和對話品質維度上裁判共識度仍面臨碰撞，體現了文學審美的多樣性，相關警示與明細已完整記錄於報告的「裁判間分歧度深度剖析」中。
